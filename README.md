## 🧑‍💻 About me

I'm an **Information Systems** student at **CIn – UFPE** (Recife, Brazil) who builds end-to-end products: from the database and API to the interface the user actually touches.

- 🛠️ I work across the stack with **Next.js + TypeScript** on the front end and **Node.js** or **Python (FastAPI)** on the back end.
- 🤖 Lately I've been focused on **AI-powered applications**: LLM agents, RAG with **pgvector**, embeddings and grounded chat over real data.
- ⚙️ I started out in **Python + RPA**, automating repetitive processes, and I still love turning manual work into code.
- 📦 I care about the product side too: specs, ADRs, clean architecture, tests and shipping things people use.

## 🎯 What I'm aiming for

- Grow as a **full-stack engineer** building AI-first products with real users and real impact.
- Go deeper on **system design**, **LLM engineering** (agents, evals, retrieval) and **cloud infrastructure**.
- Contribute to teams and open source projects where engineering and product walk together.

## 🌟 Featured projects

### 🐂 [BullCapital](https://github.com/BullCap/BullCapital)
A Brazilian market-intelligence platform. Instead of a generic chatbot telling you where to invest, it works as a **radar**: it detects relevant market signals and turns them into clear, source-backed analysis cards.
`Next.js 15` `TypeScript` `FastAPI` `Agno + OpenAI` `PostgreSQL + pgvector` `Prisma` `SQLAlchemy` `NextAuth` `Docker` `Railway`

### 🎙️ [Shift Briefing: Meeting Insights](https://github.com/viniciuslidington/coforgehackathon) · *Coforge Hackathon*
Processes recorded meetings (VTT transcripts) into summaries, a **chat grounded in the transcript**, and a deterministic, embedding-based **priority score** for the topics each user cares about.
`Next.js` `TypeScript` `Python` `FastAPI` `OpenAI` `Embeddings`

### 🪟 [MacSnap](https://github.com/viniciuslidington/MacSnap)
A native macOS window manager in **pure Swift** that brings Windows 11-style Snap Layouts and paired split resizing to the Mac, with an Apple Glass UI. Universal binary (Apple Silicon + Intel) and one-line install.
`Swift 6` `macOS` `AppKit` `Accessibility API`

### 🔄 [converter-file](https://github.com/viniciuslidington/converter-file)
A cross-platform CLI (with an Electron front end) to convert video, audio, images, documents and PDFs, with native file pickers, batch mode and estimated output sizes.
`Python` `ffmpeg` `Pandoc` `OCRmyPDF` `Electron`

### 📅 [Daily](https://github.com/viniciuslidington/DailyApp) & [ScheduleMe](https://github.com/viniciuslidington/SchaduleMe)
Two mobile-first PWAs for routines: **Daily** is an offline-first reminder app, and **ScheduleMe** turns fixed commitments, flexible activities and well-being constraints into a weekly routine.
`Next.js` `TypeScript` `Tailwind` `Supabase` `TanStack Query` `Zustand` `Dexie` `Vitest` `Playwright`

### 🤝 [Hub Doações: Bora Impactar](https://github.com/viniciuslidington/Bora-Impactar)
A platform that connects NGOs and donors, letting NGOs request donations and redistribute unused or near-expiry resources to other institutions. Architecture decisions documented as ADRs.
`React` `Vite` `React Query` `Tailwind` `Node.js` `Express` `Prisma` `PostgreSQL` `Docker`

### 📚 [Capyba Academy: RESTful API challenge](https://github.com/viniciuslidington/API-RESTful-Capyba)
A learning hub for sharing courses and articles inside a company, with JWT auth, e-mail verification, admin permissions and automated tests.
`Node.js` `Express` `Prisma` `PostgreSQL` `Jest` `Supertest` `React` `Nginx` `Docker`
